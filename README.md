# Weaponizing OBS WebSocket
Proof-of-concept code and supporting material for the **Weaponizing OBS WebSocket** research series.
The series focuses on mapping and abusing the capabilities exposed through `obs-websocket`, including RPC functionality, localhost trust boundaries, file and media interaction, and unexpected behavior produced by combining legitimate OBS features.
Detailed write-ups, methodology, and technical analysis are published on:

**https://blog.catakan.net**

## Repository Structure
```text
weaponizing-obs-websocket/
├── 01-reading-text-files/
│   ├── README.md
│   └── poc.html
├── 02-...
├── 03-...
└── README.md
```

Each directory corresponds to a post or research topic from the series and contains the relevant PoC code and supporting notes.

## Usage

The PoCs are provided for security research, testing, and educational purposes.
Only use them against systems you own or have explicit authorization to test.
